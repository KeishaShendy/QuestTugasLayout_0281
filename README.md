Tugas ini diselesaikan dengan membangun layout menggunakan Jetpack Compose. Dimulai dengan membuat data class StudentData untuk menampung data mahasiswa, lalu menyusun tampilan memakai Column dan LazyColumn untuk menampilkan daftar Card.
Komponen Card dipisahkan ke fungsi MahasiswaCard() agar bisa dipakai berulang. Semua teks, warna, dan gambar dimasukkan ke resource, sehingga kode hanya memanggilnya tanpa hardcode. Tampilan akhir disesuaikan dengan desain referensi.
